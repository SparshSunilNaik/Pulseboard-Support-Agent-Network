QUESTION:
Can a read-only user create API credentials?

ANSWER:
Yes, only Owner and Admin roles can access the API credentials page. Read-only and Editor roles receive 403 from the credentials endpoint. However, a read-only user cannot create API credentials, create reports, modify settings, invite users, or access the application token page at all. The API credentials page returns a 403 for Read-only accounts. To create an API credential, sign in as Owner or Admin, open Settings > API credentials, create a new key, copy the secret once, and then use it to create the API key. Editor/Read-only roles have no access to the API credentials page, and the API refuses their tokens (HTTP 403).
Follow-up: Is there any way to grant API-key access to lower roles? Yes, see User roles and permissions. For example, you can grant API key access to Editor/Read-only roles by creating a new API key for them. This will allow them to view and edit reports, but not make changes to other parts of the application. You can also assign these roles to specific users within the organization
